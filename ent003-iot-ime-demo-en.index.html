01The market problem

Filters on the market come in one standard size with a fixed pore size, so they cannot fit very different pollution scenarios such as formaldehyde in a new flat or pet particles. The purification result ends up much the same everywhere, so consumers just pick the cheapest one and the product slides into price competition.

02What IoT does

Several sensors collect indoor PM2.5, formaldehyde, temperature and humidity data, and AIoT uploads it to the cloud. Cloud AI identifies the pollution scenario, calculates the filter pore parameters that fit it, and keeps monitoring how worn the filter is.

03IME 3D-printed filters

IME takes the pore parameters from the cloud and prints a filter with the matching pore size layer by layer, so no mould is needed. Users first receive a set of prefabricated universal filters, and once enough environment data has been collected the company can offer a paid custom filter service.

04The closed loop

Sense, calculate, print, feed back. Filter wear and usage data keep flowing to the R&D team, the cloud corrects the pore parameters, and IME prints the next generation, so the service becomes more accurate the longer it is used.
